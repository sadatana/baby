# 成長曲線の基準値の照合記録

アプリのグラフに使っている基準値の出典と、照合の結果をまとめます。

## 1. 胎児の推定体重（`public/js/standards.js` の `FETAL_EFW_TABLE`）

### 使っている値
日本産科婦人科学会「胎児体重の妊娠週数ごとの基準値」（日本超音波医学会 2003 年「超音波胎児計測の標準化と日本人の基準値」に基づく）

| 妊娠週数 | −2.0SD (g) | 平均 (g) | +2.0SD (g) |
| --- | ---: | ---: | ---: |
| 18週0日 | 126 | 187 | 247 |
| 20週0日 | 210 | 313 | 416 |
| 22週0日 | 320 | 469 | 618 |
| 24週0日 | 461 | 660 | 859 |
| 26週0日 | 639 | 892 | 1,145 |
| 28週0日 | 853 | 1,163 | 1,473 |
| 30週0日 | 1,098 | 1,470 | 1,842 |
| 32週0日 | 1,368 | 1,805 | 2,242 |
| 34週0日 | 1,649 | 2,156 | 2,663 |
| 36週0日 | 1,927 | 2,507 | 3,087 |
| 38週0日 | 2,181 | 2,838 | 3,495 |
| 40週0日 | 2,388 | 3,125 | 3,862 |

アプリでは ±2.0SD の値から SD を求め、週と週の間は直線で補間し、平均 ±1.5SD の範囲を帯として表示しています。

### 照合の結果（2026-10-04）
- 開発環境からは学会の PDF を直接開けなかったため、学会の資料を引用している複数の独立した情報源と照らし合わせました。
- 全 12 週の平均値、および 18・36・38・40 週の −2.0SD の値が、複数の情報源で上の表と一致しました。
- 表の内部の整合性も確認しました。平均から ±2.0SD までの幅は、上下でほぼ同じです（差は数 g 以内）。

**結論:** 2003 年基準の値として、アプリの表は正しく転記されています。

### 新しい基準値（JSUM2025）について
日本超音波医学会が、胎児超音波計測の**新しい基準値（JSUM2025）**を公表しています。
- 2025 年 12 月に案として意見募集が行われ、2026 年 3 月付で公示されています。
- 2023〜2024 年に集めた約 3,700 例をもとに作られました。
- 背景には、従来の基準作成後に日本の出生体重が減ってきたことなどがあります。

新しい基準値の数値表は、開発環境からは取得できませんでした。産院が新基準に切り替えると、健診で言われる評価とアプリのグラフの帯が少しずれる可能性があります。

**今後の対応案:** JSUM2025 の基準値表（`taijikeisoku_202603.pdf`）を入手して表を差し替え、出典の表記を更新します。表の形式は同じなので、`FETAL_EFW_TABLE` を置き換えるだけで済みます。

## 2. 出生後の発育曲線（`public/js/who-percentiles.js`）

WHO Child Growth Standards の公式 LMS 表から計算した値です（`scripts/gen-who-percentiles.py`）。
WHO が公表している値と一致することを確認済みです（男児の体重の中央値: 出生時 3.35kg・12ヶ月 9.65kg・36ヶ月 14.34kg など）。
日本の母子健康手帳（乳幼児身体発育調査）の曲線とは少し異なります。アプリ内にもその旨を表示しています。
