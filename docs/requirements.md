# 要件定義書 v1.0: 赤ちゃん成長記録機能

既存の「マタニティ手帳」PWA を拡張し、妊娠中から乳幼児期まで赤ちゃんの成長を一続きで記録し、家族と共有できるようにする。

- 作成日: 2026-10-03
- 改訂: v0.1 ドラフト → v1.0（未決事項を確定。基盤を Cloudflare に決定）
- ステータス: 確定（「9. 実装前の確認事項」は設計フェーズで確認する）

---

## 1. 背景・目的

### 背景
- 現行アプリは「ママの妊娠経過」の支援（週数表示、ママの体重、陣痛タイマーなど）が中心で、**赤ちゃん自身の記録**（エコーの計測値・写真・出生後の成長）を残す場所がない。
- データは端末内（localStorage）だけに保存されるため、**パートナーや両親など家族と記録を共有できない**。機種変更でデータを失うおそれもある。

### 目的
1. 妊娠中の胎児の計測値から、出生後の身長・体重までを**一本のタイムライン・成長曲線**として残せる。
2. エコー写真や成長の写真、「初めてのできごと」を**アルバムとして振り返れる**。
3. **家族（パートナー、両親など）と記録を共有**する。パートナーは一緒に記録し、両親などは見るだけ・リアクションだけできる。

### 成功の目安
- 健診のたびに 1 分以内で計測値と写真を記録できる。
- 家族が自分の端末でアプリを開いたとき、最新の記録が見られる。
- 両親（スマホ操作に慣れていない人も含む）が招待リンクを開くだけで参加できる。

## 2. 対象範囲

| 区分 | 内容 |
| --- | --- |
| 対象期間 | 妊娠判明 〜 未就学（**主に 0〜3 歳**。成長曲線の標準値は乳幼児身体発育調査の範囲） |
| 対象ユーザー | 妊婦本人、パートナー、両親・祖父母などの家族 |
| 対応端末 | スマートフォン（iOS Safari / Android Chrome）を主対象。PC ブラウザでも閲覧可 |
| 提供形態 | PWA（ホーム画面に追加して利用）。配信・サーバーとも **Cloudflare** |

### 対象外（今回のスコープ外）
- 授乳・おむつ・睡眠などの日々の育児ログ
- 医療機関とのデータ連携、医療的な診断・判定
- 予防接種スケジュール管理
- ネイティブアプリ（App Store / Google Play）での配布

## 5. 非機能要件

| 区分 | 要件 |
| --- | --- |
| プライバシー・セキュリティ | 写真・記録は家族グループのメンバーだけが閲覧可。**権限チェックはすべてサーバー（Workers）側で行う**。写真ファイルも公開 URL にせず、認証付きで配信する。通信は HTTPS。セッションは HttpOnly / Secure / SameSite Cookie |
| オフライン | オフラインでも閲覧・記録でき、オンライン復帰時に自動送信する（写真のアップロードも再開） |
| 同期の競合 | 同じ記録を同時編集した場合は後から保存した方を優先する。削除は「削除済み」印で同期し、30 日間は管理者が復元できる |
| パフォーマンス | 初回表示 3 秒以内（4G 回線）。写真一覧はサムネイルを遅延読み込み |
| 容量 | 想定: 1 家族で 3 年間に写真 2,000 枚（約 2〜3GB） |
| 可用性・バックアップ | DB は Cloudflare D1 のタイムトラベル（過去 30 日の任意時点に復元）を利用。ユーザー自身も ZIP エクスポートで保全できる |
| アクセシビリティ | 文字サイズ変更に追随、色だけに頼らない表示、ダークモード対応（既存踏襲） |
| 医療情報の扱い | 標準曲線との比較は「目安」と明記し、診断的な表現（異常・正常の判定）はしない。標準値の出典をアプリ内に記載 |
| 運用コスト | 個人・家族利用の規模で **Cloudflare の無料枠内**で運用できること |
| 退会 | アカウント削除・グループ削除時にクラウド上のデータ（写真含む）を完全に削除する |

## 7. 技術方針（Cloudflare）

| 項目 | 採用 | 備考 |
| --- | --- | --- |
| 配信 | **Cloudflare Workers（静的アセット配信）** | 画面と API を同じドメインで配信（Cookie 認証が素直に使える）。GitHub Pages からは移行する |
| API | **Cloudflare Workers** | 認証、権限チェック、データの読み書き、写真の配信 |
| データベース | **Cloudflare D1**（SQLite） | 6 章のテーブル。タイムトラベルでバックアップ |
| 写真・動画 | **Cloudflare R2** | 非公開バケット。Workers が権限を確認してから配信。アップロードも Workers 経由 |
| ログイン | **パスキー（WebAuthn）を Workers で実装** | 外部サービス不要で Cloudflare 内で完結。パスワード・メール送信が不要で、iPhone/Android の指紋・顔認証だけでログインできるため両親でも使いやすい |
| 同期 | 端末側は IndexedDB に保存し、API と差分同期（`updatedAt` 以降の変更を取得、未送信の変更をキュー送信） | オフライン対応の要。リアルタイム通知が必要になれば Durable Objects（WebSocket）を追加 |
| フロントエンド | 既存の素の JS + PWA を継続（ビルドなし） | 写真圧縮は Canvas、グラフは SVG で自前描画 |
| サーバー側コード | TypeScript ＋ Wrangler（Cloudflare 公式 CLI） | テストは Vitest（Workers 用プール） |
| デプロイ | GitHub Actions からテスト後に `wrangler deploy` | Cloudflare の API トークンを GitHub のシークレットに登録 |

### ログイン方式を補足
- パスキーは iOS 16 以降・Android 9 以降で利用可能。iCloud キーチェーン / Google パスワードマネージャーで同期されるため、同じアカウントの機種変更ならそのまま使える。
- 別の端末からも使いたい場合は F-67、すべて失った場合は F-68 で対応する。
- 将来 Google ログインなどを追加する場合も、Workers に OAuth を追加すれば対応できる（データ構造は変更不要）。

### 無料枠の目安（2026-10 時点の公表値。実装前に再確認）
| サービス | 無料枠 | 想定使用量 |
| --- | --- | --- |
| Workers | 10 万リクエスト/日 | 家族数人で 1 日数百〜数千 |
| D1 | 5GB、読み取り 500 万行/日 | 数 MB |
| R2 | 10GB 保存、取り出し料金なし | 3 年で 2〜3GB（動画を入れると増加） |

※ R2 の有効化には Cloudflare アカウントへの支払い方法の登録が必要（無料枠内なら請求なし）。

## 9. 実装前の確認事項
1. Cloudflare アカウントの用意（R2 用の支払い方法登録を含む）と、利用するドメイン（`*.workers.dev` の無料サブドメインで良いか、独自ドメインを使うか）
2. 胎児発育曲線・乳幼児身体発育曲線の数値データの入手と、アプリ内に掲載する出典表記
3. 現在の GitHub Pages の公開 URL からの移行方法（旧 URL で開いた人に新 URL を案内する）
